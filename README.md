# Codex 全景指南

> 从认识 Codex 到建立完整的 AI 智能体工作流

《Codex 全景指南》是一本面向普通读者的 Codex 科普与实践指南。它不以编程为唯一主题，而是系统介绍如何使用 Codex 与相关 AI 工具完成研究、分析、文档、表格、演示、内容创作、网站制作、自动化和项目管理。

## 写作原则

- 目录清晰，正文完整。
- 实践优先，但解释必要的原理。
- 不只展示成功，也分析失败和能力边界。
- 不只教读者使用功能，也教读者定义任务、控制过程和验收结果。
- 容易变化的模型、价格、套餐和命令通过在线内容持续更新。
